кодогенерация

Прозрачное
понижение.

Каждая конструкция порождает код по документированному правилу, поэтому ассемблер предсказуем из исходника — без запуска компилятора.

цена

Ничего
скрытого.

Нет скрытых выделений памяти, скрытого потока управления и таблиц виртуальных методов — поведение следует из исходника, его манифеста и соглашений языка.

проверки

Верно —
или ловушка.

Операции проверяются по умолчанию; внутри области unchecked их поведение задаёт железо, а не то, что удобно компилятору.

Одна форма,
сверху донизу.

Форма объявления одна — name : type = value. Типы, функции и обобщения — такие же значения, записанные так же, поэтому на каждом уровне не нужно учить новое.
